# STEM App — метод ограничений для MOLP

Веб-приложение, реализующее итеративный метод STEM (Benayoun et al., 1971) 
для решения многокритериальных задач линейного программирования.

## Требования

- Любой современный браузер: Chrome 90+, Firefox 88+, Edge 90+, Safari 14+
- Интернет НЕ требуется
- Установка Python/pip/библиотек НЕ требуется

## Запуск

1. Распакуйте архив `stem_app.zip`.
2. Откройте файл `index.html` двойным кликом.
3. Приложение откроется в браузере — можно работать.

## Как пользоваться

1. Введите матрицу `A`, вектор `b`, матрицу `C` в левой панели.
2. Нажмите «Запустить / пересчитать».
3. Изучите pay-off table и текущее решение.
4. Выберите критерий `j*` и величину уступки `Δ`, нажмите «Ослабить».
5. Изучите блок «Что изменилось в цикле N» и историю циклов.
6. Повторяйте, пока решение не устроит.
7. Нажмите «Завершить» — поиск остановлен.

## Тестовый пример

**Входные данные:**

    A = [1,1; 0,1; 1,0]
    b = [10; 6; 8]
    C = [3,2; 1,4]

**Ожидаемый результат — pay-off table:**

|       | C1 | C2 |
|-------|----|----|
| max C1 | 28 | 16 |
| max C2 | 24 | 28 |

Если видите эти числа — приложение работает корректно.

## Ограничения

- Только ограничения `Ax ≤ b`, `x ≥ 0` (нет равенств и ограничений `≥`)
- Только максимизация критериев (для минимизации умножьте строку `C` на −1)
- Нет целочисленных переменных
- Размерность ограничена производительностью браузера
